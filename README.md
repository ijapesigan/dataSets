## Description

Data sets used in the examples and tests of other projects in R (R Core
Team, 2026).

## Installation

You can install the development version of `dataSets` from
[GitHub](https://github.com/ijapesigan/dataSets) with:

``` r
if (!require("pak")) install.packages("pak")
pak::pkg_install("ijapesigan/dataSets")
```
